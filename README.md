# Finora

**Take control of your money.**

Finora is a modern, privacy-focused personal finance app for Android, built entirely with Kotlin and Jetpack Compose. It helps you track income and expenses, manage budgets, organize transactions, and understand your spending habits through interactive analytics.

Designed with a clean Material 3 interface and an offline-first approach, Finora keeps your financial data stored locally on your device.

### Key Features
- Income and expense tracking
- Custom categories and monthly budgets
- Interactive financial analytics and charts
- Transaction search and filtering
- Multi-currency support
- German and English localization
- Local data storage and JSON backup
- Material You dynamic theming
- Android home screen widget

### Built With
Kotlin · Jetpack Compose · Material 3 · Room · DataStore · Coroutines

### Privacy First
No account required. No cloud dependency. Your financial data stays on your device.
